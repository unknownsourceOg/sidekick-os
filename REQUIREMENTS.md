# Sidekick: agreed product requirements

The user wants a free AI integrated into the desktop, represented by a persistent
animated friend. They should be able to describe a task and choose clear buttons
instead of typing administrative commands. The desktop should have a dark hacker
style. Coding, music, and animation are first-class uses, alongside computer help.

The model assists with reasoning and creation. Supported system operations use
explicit, validated controls with useful progress and honest success/failure
results. Generated commands are suggestions until reviewed; model prose must not
silently execute as root. Existing files need backups before replacement.

This delivery includes a desktop hub, animated character, local chat with domain
modes, graphical model setup, diagnostic tools, reviewed file saving, MIDI starter
projects, a Blender animation starter, and launch/install buttons for free creative
tools. Local inference runs without a subscription after the initial downloads.
Model capability and speed depend on hardware; no claim of universal correctness.

Boot repairs remain part of this project. A successful archive build alone is not
proof of a working desktop. Verify dependencies, GUI startup and a live Linux boot.

Later work must not replace this goal with only an ISO repair or a terminal-only
assistant. Advanced autonomous app control, voice, audio generation and training
are separate capabilities and must not be advertised before implemented/tested.
